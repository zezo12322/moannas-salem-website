## MOBILE WIREFRAME NOTES

- Hero: Full-width, stacked CTA buttons (vertical, full-width)
- Quick Support Cards: 2-column grid on mobile, 1-column on very small screens
- Issues: Single-column cards
- Navigation: Hamburger menu → slide-in drawer from right (RTL)
- Sticky bottom bar on mobile: [اطلبي دعمًا] CTA always visible
- Campaigns: Horizontal scroll carousel
- Guide articles: Card list, search bar pinned at top

---

## KEY DESIGN DECISIONS

1. **Trust signal appears within hero** — privacy note is never buried below fold
2. **"أنا محتاجة" framing** — user-centric, not institution-centric
3. **No emergency hotline implied** unless institution can guarantee real-time response
4. **Testimonies section uses anonymized quotes** — never names, never photos
5. **Institutional CTA is separate block** — so it doesn't compete with primary (support) CTA
